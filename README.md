# Dashboard de Marketing: Recargas, Packs y NPS

Dashboard desarrollado en **Power BI** como herramienta de análisis para el área de **marketing**, orientado a tomar decisiones sobre campañas y rentabilidad a partir del comportamiento de clientes.

## Archivos incluidos

- `Dashboard Taller I - Tartarini Luciano Aquiles.pbix`  
  Archivo principal del dashboard (Power BI).

- `Definición Funcional del Dashboard - Tartarini Luciano Aquiles.docx`  
  Documento funcional con objetivo del dashboard y usos clave para marketing.

- `Reporte Explicativo - Tartarini Luciano Aquiles.xlsx`  
  Reporte explicativo de KPIs (definición en palabras, lógica utilizada y pestaña donde aparece cada KPI).

## Pestañas del dashboard (Power BI)

El archivo `.pbix` contiene **2 pestañas**:
- **Recargas**
- **Packs y Puntaje**

## KPIs documentados (según el XLSX)

**Recargas**
- Total de Clientes
- % de Recargas Semanales
- % de Clientes Retenidos con Recargas
- Monto Promedio de Recargas Semanales

**Packs y Puntaje**
- % de Clientes que Compraron un Pack por Semana
- % de Detractores, Neutros y Promotores
- Net Promoter Score (NPS)
- % de Clientes sin Puntaje

## Cómo abrir y revisar el proyecto

1. Instalar **Power BI Desktop**.
2. Abrir el archivo:
   - `Dashboard Taller I - Tartarini Luciano Aquiles.pbix`
3. Para entender el propósito y el uso del dashboard:
   - Leer `Definición Funcional del Dashboard - Tartarini Luciano Aquiles.docx`
4. Para ver el detalle de definición y lógica de cada KPI:
   - Abrir `Reporte Explicativo - Tartarini Luciano Aquiles.xlsx`

## Notas

- El documento DOCX describe el objetivo del dashboard y cómo cada KPI aporta a decisiones del área de marketing.
- El XLSX resume la lógica utilizada para las medidas y en qué pestaña se visualiza cada KPI.
