# Dashboard-de-Marketing-Recargas-Packs-y-NPS
ashboard en Power BI para el área de marketing: analiza recargas semanales, retención de clientes por recarga, monto promedio de recargas, compra de packs por semana y métricas de satisfacción (NPS, detractores/neutros/promotores y % sin puntaje) en dos páginas.
